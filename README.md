# אנקור – בדיקת כיסוי ביטוחי צד ג'

תוכנת Windows (קובץ EXE אחד, ללא התקנה) שמקבלת **מספר רישוי** ו**תאריך אירוע**, נכנסת במקביל ל-16 אתרי חברות הביטוח ומציגה באיזו חברה הרכב היה מבוטח.

## הורדה
1. בלשונית **Actions** במאגר ← הריצה האחרונה של *Build Windows EXE* ← **Artifacts** ← `AnkorInsuranceCheck`.
2. מחלצים את ה-ZIP לתיקייה כלשהי (אפשר גם דיסק-און-קי) ומפעילים `AnkorInsuranceCheck.exe`.

דרישות: Windows 10/11 עם Microsoft Edge (מותקן כברירת מחדל) או Google Chrome.

## איך עובדים
1. מזינים מספר רישוי ותאריך אירוע ולוחצים **בדוק בכל החברות**.
2. נפתח חלון דפדפן עם לשונית לכל חברה; התוכנה ממלאת את הפרטים ושולחת.
3. אתר שמציג "אני לא רובוט" / קוד אימות מסומן בכתום (**דורש פעולה**) – לוחצים **הצג באתר**, משלימים, והתוכנה קולטת את התשובה לבד.
4. כרטיס ירוק = **מבוטח**. לכל אתר נשמר צילום מסך + קובץ `סיכום.csv` בתיקייה `תוצאות` ליד התוכנה.

## התאמת אתרים (ללא בנייה מחדש)
הקובץ `sites.json` שליד ה-EXE קובע את רשימת האתרים. כברירת מחדל התוכנה מזהה את השדות לבד; כשאתר משתנה אפשר להוסיף לו:

| שדה | משמעות |
|---|---|
| `plate_selector` / `date_selector` / `submit_selector` | סלקטור CSS מדויק לשדה / לכפתור |
| `pre_click` | רשימת סלקטורים ללחיצה לפני המילוי (למשל לשונית "צד ג'") |
| `date_format` | `dd/mm/yyyy` (ברירת מחדל), `dd.mm.yyyy`, `ddmmyyyy` וכו' |
| `positive` / `negative` | ביטוי רגולרי נוסף לזיהוי "מבוטח" / "לא מבוטח" |
| `enabled` | `false` כדי לדלג על אתר |

## פיתוח
```
pip install -r requirements.txt
python app/main.py          # הרצת התוכנה
python tests/test_engine.py # בדיקות המנוע מול טפסים מדומים
```
