# 😼 אוליבר המעורר

שעון מעורר לאנדרואיד שבו החתול אוליבר מעיר את עידו.

- **תאריך ושעה מדויקים** – הקלדת שעה מדויקת (24 שעות): שעה שעוד לא עברה היום נקבעת להיום, אחרת למחר. אפשר גם לבחור תאריך ספציפי בלוח שנה. חד-פעמי, או כל יום החל מהתאריך שנבחר.
- **הקול של אוליבר** – הקלטה מנוקה מרעשי רקע (דנויז ספקטרלי + חיתוך למיאו בלבד), מתנגנת בלופ ובכל סבב במצב רוח אחר, בעוצמה עולה ועם רטט.
- **התמונות מתחלפות** – 4 תמונות של אוליבר, מוצגות במלואן (מותאמות למסך) על רקע מטושטש של עצמן, במסך הראשי ובמסך ההשכמה.
- **כדי לכבות צריך ללטף את אוליבר 10 פעמים.** כפתור הנודניק בורח בשתי הלחיצות הראשונות.
- **📞 אוליבר מתקשר ללילך** – ברגע שהמעורר מצלצל, אוליבר מחייג ברמקול ללילך. המספר נמצא אוטומטית מאנשי הקשר (או נבחר ידנית). בהדגמה אפשר לבחור אם להתקשר.

## התקנה
- APK: https://github.com/captainido/git-practice/releases/latest/download/CatAlarm.apk
- RAR: https://github.com/captainido/git-practice/releases/latest/download/CatAlarm.rar

באנדרואיד יש לאשר "התקנה ממקורות לא ידועים" לדפדפן.

## בנייה
GitHub Actions (`.github/workflows/cat-alarm.yml`) בונה APK חתום ומפרסם Release (APK + RAR) בכל push.
מקומית: `cd CatAlarm && ./gradlew assembleRelease`.
