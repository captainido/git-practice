# אוליבר · שעון מעורר

שעון מעורר פרימיום לאנדרואיד, בהתנהגות של אפליקציית השעון של אנדרואיד, עם הקול והתמונות של אוליבר.

- **כמה התראות** – חד-פעמיות או חוזרות לפי ימים, עם תאריך מסוים לפי הצורך, תווית ורטט לכל התראה.
- **שעה נכונה** – שעה שנבחרה נקבעת למועד הקרוב ביותר (היום אם עוד לא עברה).
- **מסך התראה** – שעה גדולה, תמונה של אוליבר, כפתורי "עצירה" ו"נודניק". חזרה לא משתיקה; לחצני העוצמה לפי ההגדרה.
- **התראות מערכת** – התראה קרובה (שעתיים לפני, עם ביטול מראש), נודניק פעיל, התראה שהוחמצה.
- **📞 שיחה ברקע** – עם הצלצול מתבצעת שיחה ברמקול לאיש הקשר (לילך, נמצא אוטומטית), ומסך ההתראה חוזר מעל מסך השיחה.
- **הגדרות** – משך נודניק, השתקה אוטומטית, הגברה הדרגתית, לחצני עוצמה, תצוגה מקדימה.

מערכת העיצוב מתועדת ב-[DESIGN_SYSTEM.md](DESIGN_SYSTEM.md).

## התקנה
- APK: https://github.com/captainido/git-practice/releases/latest/download/CatAlarm.apk
- RAR: https://github.com/captainido/git-practice/releases/latest/download/CatAlarm.rar

באנדרואיד יש לאשר "התקנה ממקורות לא ידועים" לדפדפן.

## בנייה
GitHub Actions (`.github/workflows/cat-alarm.yml`) בונה APK חתום ומפרסם Release (APK + RAR) בכל push.
מקומית: `cd CatAlarm && ./gradlew assembleRelease`.
