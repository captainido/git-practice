# 😼 החתול המעורר (Cat Alarm)

שעון מעורר לאנדרואיד שבו החתול הוא המעורר.

- בוחרים שעה (חד-פעמי או כל יום).
- בזמן ההשכמה: ההקלטה של החתול מתנגנת בלופ, ובכל סבב במצב רוח אחר (צ'יפמאנק, חתול-ענק, סלואו-מושן...), עם עוצמה שעולה בהדרגה ורטט.
- המסך: החתול מתנדנד, קופץ על המסך ומטיח בך עקיצות. כפות ודגים נופלים מהשמיים.
- **כדי לכבות צריך ללטף את החתול 10 פעמים.**
- כפתור הנודניק בורח בשתי הלחיצות הראשונות. בשלישית - 5 דקות.

## התקנה
הורדה: https://github.com/captainido/git-practice/releases/latest/download/CatAlarm.apk
באנדרואיד יש לאשר "התקנה ממקורות לא ידועים" לדפדפן.

## בנייה
GitHub Actions (`.github/workflows/cat-alarm.yml`) בונה APK חתום ומפרסם Release בכל push.
מקומית: `cd CatAlarm && ./gradlew assembleRelease`.
