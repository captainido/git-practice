# 🐱 מצלמת חתול — CatCam

אפליקציית אנדרואיד שהופכת את הטלפון למצלמת אבטחה לחתול:
ברגע שהמצלמה מזהה חתול היא **משמיעה צליל**, **מצלמת תמונה** (עם תאריך ושעה מוטבעים),
שומרת אותה בגלריה (`Pictures/CatCam`) ו**שולחת אותה ללילך בוואטסאפ** עם תאריך ושעת הזיהוי.

## התקנה

1. הורידו את הקובץ [`dist/CatCam.apk`](dist/CatCam.apk) לטלפון.
2. פתחו אותו. אם אנדרואיד שואל — אשרו "התקנה ממקורות לא ידועים" עבור הדפדפן/מנהל הקבצים.
3. אם Play Protect מזהיר ("אפליקציה לא מוכרת") — "פרטים נוספים" ← "התקן בכל זאת".
   זה קורה לכל אפליקציה שלא הגיעה מחנות Play.

## הגדרת Green-API (פעם אחת, ~5 דקות)

וואטסאפ לא מאפשר לאפליקציות לשלוח הודעות אוטומטית, לכן משתמשים ב-Green-API —
שירות שמתחבר לוואטסאפ שלך כ"מכשיר מקושר" (בדיוק כמו וואטסאפ ווב).

1. היכנסו ל-<https://console.green-api.com> והירשמו.
2. צרו Instance חדש ובחרו בתוכנית **Developer** (חינמית — עד 3 צ'אטים בחודש, מספיק ללילך).
3. בוואטסאפ בטלפון: **הגדרות ← מכשירים מקושרים ← קישור מכשיר**, וסרקו את קוד ה-QR שבקונסול.
4. העתיקו מהקונסול לאפליקציה ארבעה ערכים: `idInstance`, `apiTokenInstance`, `apiUrl`, `mediaUrl`.
5. הזינו את מספר הטלפון של לילך (למשל `0501234567`), לחצו **שמור הגדרות**,
   ואז **שלח הודעת בדיקה ללילך** — אם היא קיבלה, הכל מוכן.

> ההודעות נשלחות **מהוואטסאפ שלך** ללילך.

## שימוש

1. לחצו **הפעל מצלמה** ואשרו הרשאות מצלמה והתראות.
2. כוונו את הטלפון לאזור שהחתול מגיע אליו. אפשר לכבות את המסך — המצלמה ממשיכה לעבוד ברקע
   (יופיעו התראה קבועה ונקודה ירוקה של מצלמה — זה תקין).
3. לעצירה: כפתור **עצור מצלמה** באפליקציה, או "עצור" בהתראה.

### הגדרות
| הגדרה | ברירת מחדל | הסבר |
|---|---|---|
| דקות המתנה בין התראות | 5 | כדי שלילך לא תקבל 100 הודעות כשהחתול יושב מול המצלמה |
| רף ביטחון לזיהוי | 70% | גבוה = פחות התראות שווא, נמוך = פחות פספוסים |
| מצלמה קדמית | כבוי | ברירת המחדל היא המצלמה האחורית (איכותית יותר) |
| צליל בזיהוי | פועל | צפצוף בערוץ ההתראות/שעון מעורר |

## חשוב לדעת

- **סוללה:** מצלמה שרצה ברציפות מרוקנת סוללה מהר — **חברו למטען** כשהמצלמה פועלת.
  מומלץ ללחוץ "הגדרות סוללה" ולהגדיר את האפליקציה **ללא הגבלה**, אחרת חלק מהיצרנים
  (בעיקר שיאומי/סמסונג) עלולים לעצור אותה ברקע.
- **בזמן שהמצלמה פעילה, אפליקציות אחרות לא יכולות להשתמש במצלמה** (מגבלה של אנדרואיד).
- **זיהוי:** המודל מזהה "חתול" באופן כללי (מודל ML Kit של גוגל שרץ על המכשיר, בלי אינטרנט).
  מכיוון שאין חתולים נוספים בבית, זה מספיק. החתול צריך להופיע בשתי פריימים רצופים כדי למנוע התראות שווא.
- אם אין אינטרנט ברגע הזיהוי — התמונה נשמרת ותישלח אוטומטית כשהחיבור יחזור.

## בנייה מהקוד

```bash
./gradlew assembleRelease   # דורש Android SDK (ANDROID_HOME)
# הפלט: app/build/outputs/apk/release/app-release.apk
```

הקוד: Kotlin · CameraX · ML Kit Image Labeling · WorkManager · OkHttp. מינימום אנדרואיד 8.0.
